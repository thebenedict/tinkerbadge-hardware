# Datasheet sources

The JSON inventories and source records in this directory identify the exact manufacturer documents used in the component reviews, including URLs, revisions, retrieval dates, and SHA256 hashes. Each component record under `docs/components/` links to its source or source record.

Downloaded supplier PDFs, full text extractions, saved webpages, and rendered pages are kept out of the public repository pending redistribution permission. Download the originals from their recorded source URLs into the recorded filenames for local review. Verify SHA256 before treating a download as the reviewed revision; suppliers may update documents at the same URL.

See [third-party notices](../THIRD_PARTY_NOTICES.md) for scope and the KiCad library license. Project-generated schematic PDFs and PCB review images are separate project outputs.
