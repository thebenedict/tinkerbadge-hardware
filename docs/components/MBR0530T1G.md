# MBR0530T1G

Three 30 V / 0.5 A Schottky rectifiers. The actual CASE 425 STYLE 1 drawing on PDF page 4 identifies cathode pin 1 at the banded end and anode pin 2. D301 clamps the flying-capacitor node; D302 rectifies VGL; D303 rectifies VGH. Nominal rail voltage does not establish switching-overshoot margin. The discontinued row on datasheet page 1 is NRVB0530T3G, not this part.

See [display circuit decisions](../design/display.md) for voltage margins, support values, boot/off-state behavior, and release gates.
