# TS-1088-AR02016 historical component facts

Superseded on9 November2026 by [Alps SKSCLBE010](SKSCLBE010.md) for both SW401/SW402. The following describes the earlier two-terminal design only.

## Source and physical package

[TS-1088-AR02016.pdf](https://storage.googleapis.com/graviton-electric-symbols/document_assets/lcsc/2409302330_XUNPU-TS-1088-AR02016_C720477.pdf), XUNPU TS-1088 two-page catalog, no printed date/revision. [Source](https://www.xunpu.com.cn/product/liaohao/1098.html). URL, retrieval route and SHA256 are in `TS-1088-AR02016.source.json` under datasheets.

Two-terminal normally-open momentary tactile,4×2.9mm body,2.0mm height, no bottom peg. Two electrical terminals only, no four-pin duplicated contacts or EP. Project numbering explicitly assigned because source does not number contacts.

Inspected p1 exact part-code table/body and p2 two-pad land/circuit pixels. Pad1/2 centers4.15mm apart; each1.35×1.80mm per p2.

## Ratings and support circuit

12VDC50mA rating;100mΩ initial contact maximum;100MΩ insulation minimum;100,000 cycles. AR02016 selects stainless actuator, no bottom column,2.0mm height and1.6±0.5N force. Travel tolerance differs between source table and illustration; confirm enclosure tolerance with actual sample.

SW401/SW402 are user buttons. One terminalGND, other through330Ω to BTN_A_N/BTN_B_N;100kΩ pull-up to3.3V and100nF toGND at each MCU input. This gives about10ms release RC, limits initial discharge current to≈10mA and held current33µA. Use software debounce20ms starting point. BTN_A_N must be a retained deep-sleep wake input. No boot-strap function is assigned; separate recovery remains on MCU sheet. Storage wake is intentional button action, with motion wake disabled during transport.
